# vivid-html

Single-file HTML artifacts in the warm-earthy "unreasonable effectiveness of HTML" style — ivory + clay palette, serif headlines + mono eyebrows, no build step.

**Live:** https://bbbond123.github.io/vivid-html/

## What this is

A growing notebook of one-page HTML artifacts. Each idea lives at its own URL — forwardable to anyone, no login, no app. Generated by the [`vivid-html`](https://github.com/bbbond123/.claude/skills/vivid-html) Claude Code skill (a personal skill at `~/.claude/skills/vivid-html/`) and published by `bin/publish.sh`.

## Layout

```
.
├── index.html               # auto-regenerated gallery (do not hand-edit)
├── _layouts/
│   └── index-template.html  # the gallery template publish.sh fills
├── bin/
│   └── publish.sh           # one-shot: re-render index, commit, push
└── <slug>/
    └── index.html           # one artifact per slug, served at /<slug>/
```

## Adding a page

In Claude Code (the `vivid-html` skill must be installed), say something like:

> Make this into a vivid-html page about Q3 incident postmortem.

The skill will draft the file, save it under `<slug>/index.html`, then run:

```bash
bash bin/publish.sh <slug>
```

The script:

1. validates the artifact has `<title>`, `<meta name="description">`, and `<meta name="vivid:created">`;
2. regenerates `index.html` listing every existing slug (newest first);
3. commits as `bbbond123` and pushes to `origin/main`;
4. prints `URL: https://bbbond123.github.io/vivid-html/<slug>/` on the last line.
