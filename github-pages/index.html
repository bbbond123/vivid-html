01

先打个比方

三步

想象你想把一张海报贴出去给路人看：你得有海报、有橱窗、有街道。GitHub Pages 把这三件事一次性免费给你。

第一步
你做一张海报
一份 .html 文件—— 一张写好文字、带图片和样式的网页。它就是你的海报本身。
第二步
GitHub 是你的橱窗
你把海报放进 GitHub 上的一个文件夹。GitHub 是个程序员常用的网站，本来用来存代码， 顺便允许你把里面的网页公开展示。
第三步
它生成一个街道地址
GitHub 自动给你一个像 你的名字.github.io 的网址。 你把这个链接发给朋友，朋友点开就能看到你的海报。

03

它为什么免费

背后的逻辑

免费的东西总让人怀疑哪里有坑。但 GitHub Pages 是个例外——它免费，是因为送出去对 GitHub 自己也有好处。

$0 无限制使用

GitHub 是全世界最大的程序员聚集地，背后是微软。它靠企业客户付费赚钱， 所以非常希望每一个程序员都喜欢这个平台、习惯用它、推荐同事用它。

让大家免费托管自己的网页，是它最聪明的一笔投资：你做的每一个页面，都是它的一块免费招牌。 所以——它确实没坑，你尽管用，连信用卡都不用绑。

唯一的隐含约定是：托管的内容必须是公开可见的（除非你付费升级），别拿它做收费会员区或藏私密资料。

04

几步可以用上

不用编程

你不需要会写代码——现在让 AI 帮你写一份 HTML 是十秒钟的事。剩下的是把它放上去的动作，跟传文件到网盘差不多。

注册一个 GitHub 账号
和注册一个邮箱差不多，免费，大约两分钟。它会问你要用户名——这个名字会出现在你的网址里。
github.com/signup→
建一个新仓库
「仓库」就是一个文件夹的网页版本。你点几下，就有了一个属于你的空文件夹。
new repository→
把 HTML 文件拖进去
真的是「拖」——把网页文件用鼠标拖到那个网页上，松手，文件就上去了。
drag & drop→
在设置里点一下「Pages」
告诉 GitHub「请把这个文件夹当网页发布」。一两分钟后，它给你一个网址——结束。
Settings → Pages→
05

朋友最常问的几个问题

五问

这些是我每次给非技术朋友讲的时候，他们都会问的——所以一次写清楚。

Q1
需要懂编程吗？
不需要。HTML 不是「编程」，更像是带格式的纯文本。让 ChatGPT 或 Claude 帮你写一份完全可以——你只要描述清楚要什么样子。
Q2
我的网址会长什么样？
默认是 你的用户名.github.io/项目名。如果你愿意花一点钱买一个自己的域名（比如 yourname.com），也可以指过来用。
Q3
速度快吗？会不会卡？
很快。它的服务器分布在全世界，无论你朋友在哪个国家打开都很流畅——比大多数自建网站都稳。
Q4
能放视频、音乐、动态评论这些吗？
视频图片可以，但有大小限制（单个文件 100MB 以内最稳）。它适合「展示」，不适合「互动」——评论、点赞、用户登录这些功能它做不了，因为它本质上只是在送你一个静态页面。
Q5
我以后不想用了，能删吗？
能，随时。点进设置，把仓库删掉，网址马上就失效了——没有合同，没有月费，没有客服电话要打。
